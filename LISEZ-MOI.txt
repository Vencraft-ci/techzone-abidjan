TECHZONE ABIDJAN — site boutique PWA (HTML/CSS/JS, sans framework)

TEST EN LOCAL
  Double-clic sur index.html (l'installation PWA et le mode hors ligne demandent HTTPS ou localhost).
  Avec localhost : python3 -m http.server 8000  puis http://localhost:8000

HÉBERGEMENT (HTTPS obligatoire pour la PWA)
  Netlify : glissez le dossier sur app.netlify.com/drop.
  GitHub Pages : envoyez les fichiers dans un dépôt, Settings > Pages.

MODIFICATIONS (en haut de script.js)
  Numéro WhatsApp : WHATSAPP_NUMBER (ex : 2250707070707)
  Livraison offerte dès : FREE_DELIVERY_FROM (actuellement 10000)
  Tarifs de livraison : tableau ZONES
  Prix, noms, couleurs d'accent : tableau PRODUCTS (price, name, accent)
  Après chaque mise à jour : changez CACHE_VERSION dans sw.js.
